# Mastermind : stratégies de résolution en Java

Projet étudiant de décembre 2006, réalisé avec Marc Rastoix et conservé comme archive pédagogique.

Étude de trois stratégies heuristiques de résolution du Mastermind, dans le cadre de l’IA classique et de la recherche de solutions.

## Sources et documentation

Les stratégies sont implémentées dans [ThreadStrategie.java](Sources/ThreadStrategie.java), par les méthodes `strategie1`, `strategie2` et `strategie3`.

Le [rapport](Documentation/marechal-rastoix-rapport.pdf) et ses annexes décrivent les stratégies et leurs résultats. Les sources LaTeX sont conservées dans le dossier [Documentation](Documentation/).

## Exécutables historiques

Le dossier [Executables](Executables/) contient le fichier IHMMastermind.jar et les scripts de lancement Windows et Linux. Une JVM et la commande java sont nécessaires. Leur fonctionnement sur un environnement actuel n’a pas été vérifié.

![Interface du Mastermind](screenshot.png?raw=true "Interface du jeu")

Le projet reflète les outils et pratiques de cette période. Les propositions d’amélioration sont bienvenues dans les issues et les pull requests.
